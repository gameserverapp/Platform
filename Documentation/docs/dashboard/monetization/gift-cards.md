Gift card can be used to buy [Supporter Tiers](/dashboard/monetization/supporter_tiers), in a variety of ways.
For example, to compensate players or let players buy gift cards for other players.

[Go to Gift cards >](https://dash.gameserverapp.com/monetization/gift-cards)

## Create gift card

### 1. Click `+ Add gift card`

Start by clicking `+ Add gift card` in the **top-right corner** of the [Gift card overview page](https://dash.gameserverapp.com/monetization/gift-cards).

![Monetization - Create gift card 1](/img/dashboard/monetization/gift_card/create_giftcard_1.jpg)

Enter a name and hit `Create`.

![Monetization - Create gift card 2](/img/dashboard/monetization/gift_card/create_giftcard_2.jpg)

### 2. Configure settings

Set the gift card value and specify the availability period. More info about [Gift card settings >](/dashboard/monetization/gift-cards#settings)

![Monetization - Create gift card 3](/img/dashboard/monetization/gift_card/create_giftcard_3.jpg)

### 3. Activate for items

Select which Supporter Tiers it applies to in the `Activate discount for` section. This determines which items players can buy with the gift card.

![Monetization - Create gift card 4](/img/dashboard/monetization/gift_card/create_giftcard_4.jpg)


## Settings

### Gift card credit value

Set the value of the gift card.

![Monetization - Gift card settings - Gift card credit value](/img/dashboard/monetization/gift_card/credit_value.jpg)

### Used up credit

See how much of the gift card has been used.

![Monetization - Gift card settings - Card used up credit](/img/dashboard/monetization/gift_card/card_used_credit.jpg)

### Code

Players must enter this code on the Community website to redeem the gift card.

![Monetization - Gift card settings - Code](/img/dashboard/monetization/gift_card/card_code.jpg)


### Start & End date

Determine when the gift card becomes available and when it expires.

You can leave the `End date` empty to keep the gift card active indefinitely.

![Monetization - Gift card settings - Start / End date](/img/dashboard/monetization/gift_card/card_period.jpg)



## Gift card sales insight

Track purchases made using the gift card.\
You’ll also see a summary of total revenue generated through the gift card.

![Monetization - Gift card sales insight](/img/dashboard/monetization/gift_card/giftcard_sales.jpg)
